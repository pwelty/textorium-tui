- Current-source safety: stage ordinary and batch edits until Ctrl+S; refuse dirty refresh, collection-changing reloads, and dirty-selected-post editor handoff. Undo only the last changing batch's still-owned fields in memory, keeping later body/field edits and current disk baselines. Report partial save failures without clearing failed edits.

Unique exclusive same-directory temp files preserve mode and are atomically renamed after a final baseline check. Do not describe this as a filesystem transaction, full metadata preservation, or directory-fsync durability.
- Keep code-significant spaces/tabs and trailing spaces on nonblank body lines in the editable YAML/TOML projection; omit only boundary blank lines, using identical boundaries on load and save. Plain Markdown stays unprojected. Smart quotes uses four-column tab stops and one optional whitespace column after each blockquote marker; retain residual indentation so indented fence-like code is not mistaken for an opener. Test the actual read → App transform → save → reload path and real Q/Ctrl+S keys, not just the helper.
- Discovery uses conventional roots plus exact package dependency hints, prunes generated/dependency/Git directories, and does not follow symlinks or execute Eleventy config. Keep the shared discovery JSON fixtures aligned across Rust and real PTY/CLI tests. Custom `server_url` affects preview only; arbitrary permalinks remain unsupported.

Edit the existing JSON directly, preserving unknown fields; first-edit scaffolds contain no guessed site path. Resolve literal editor argv as config → VISUAL → EDITOR → nano without a shell, require explicit desktop wait flags, and restore terminal state on all handoff outcomes. `list` errors (stderr/no stdout) on missing roots rather than returning a successful empty JSON array. Keep tests/config_smoke.py synthetic and separate from native GUI/editor acceptance.
