## What shipped today

Ran two full scout-and-grind cycles across the entire textorium-tui codebase, closing 11 issues and landing 10 PRs in a single session. The work fell into three themes: infrastructure, data integrity, and UX polish.

**Infrastructure and reliability.** Stood up GitHub Actions CI (#14) with fmt, clippy, test, and build checks on every push and PR — the project had zero CI before today. Fixed 14 clippy warnings and ran cargo fmt across all source files to establish a clean baseline. Added a terminal panic hook (#19) so the terminal is always restored to a usable state, even if the app crashes. This was a well-known ratatui pitfall that was waiting to bite.

**Data integrity.** The YAML frontmatter save path was the biggest fix. The old `save_post` rewrote frontmatter through serde round-tripping, which silently reformatted dates, reordered fields, and dropped formatting. Replaced it with a line-based patching approach (#9) that preserves original formatting for unchanged fields while correctly handling adds, edits, and deletes — with 5 unit tests covering each case. Also fixed the singular `category` field being silently dropped (#10), filtered Hugo `_index.md` section files from the post list (#21), and made `scan_posts` report parse errors instead of silently swallowing them (#20).

**UX polish.** The content pane no longer uses a hardcoded 30-line limit — it adapts to the actual terminal height (#22). Scroll bounds are now checked so you can't scroll past the end of content (#11). Browser preview uses the cross-platform `open` crate instead of a macOS-only `Command::new("open")` call (#13). Empty states now show contextual guidance instead of blank panes (#23) — whether it's an unconfigured site, missing path, or no markdown files.
